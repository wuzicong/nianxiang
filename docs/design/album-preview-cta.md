## 1. 目标

| # | 原则 | 落到念册 |
|---|---|---|
| A | 单主动词 | 预览页**只有一个**实心主按钮，动词固定为 **「生成分享链接」** |
| B | 次级不抢戏 | 「返回这本」「同主题样张」= 文字链 / muted，**禁止**第二实心钮、outline 双主 |
| C | 层级一眼清 | 左：品牌屑 → 中/右：主 CTA；右端：故事/翻页；样张链最弱 |

与前端「CTA 单主动词」对齐：同一路由同时刻不得出现两个同级实心 CTA。

## 2. 文案锁定（中文 · W6）

| 角色 | 文案（唯一） | 语义 |
|---|---|---|
| 主 CTA | **生成分享链接** | 进入该册 `/albums/[id]` 分享区 / create-share 锚点（与 tweaks P0#2 一致） |
| 次 · 返回 | **返回这本** | 回相册详情，不创建分享 |
| 次 · 样张 | **同主题样张** | 开样张 `/preview`（或既有样张路由）；**layout-note** 级 |
| 切换 | **故事** / **翻页** | 版式切换，非转化 CTA；芯片或分段控件，勿写成主按钮文案 |

**禁止文案（W6）：**「分享」「立即分享」「复制链接」「导出 PDF」「邀请好友」「继续」「下一步」「生成」单字、英文 Share/Export 混排主钮。  
**加载中：** 主钮文案改为 **「生成中…」**（或保持「生成分享链接」+ `aria-busy`）；**勿**换动词族。  
**不可用：** 主钮 `disabled`；旁侧 **一行** muted 说明（如「预览未就绪」），勿弹第二 CTA。

## 3. 视觉层级

| 层 | 元素 | 规格 |
|---|---|---|
| 0 | 品牌屑「念册」等 | ≤0.875rem · muted/弱 accent 链；勿粗标题 |
| 1 · **主 CTA** | 「生成分享链接」 | 实心 · `--share-text` 底 + 反白字（或主题规定的实心 token）· weight 600 · 热区高 ≥44px · 圆角跟主题 `radius`（≤主题卡圆角；heirloom 勿粉嫩 pill） |
| 2 | 「返回这本」 | 文字链 · `--share-text` 或 muted · **无**边框底板 |
| 3 | 「同主题样张」 | `layout-note` · ≤0.8125rem · `--share-muted` · 更弱于返回 |
| 4 | 故事 / 翻页 | 右端分段；选中用 inset 或字重，**无**外投影 / scale |

**Heirloom / magazine-heirloom：** 主 CTA 用 `--share-text` 实心 + 白字（tweaks P2#10）；禁粉嫩渐变 pill。  
**Kyoto-lantern：** 深底上主钮对比 ≥4.5:1。  
**Cotton-candy：** 实心可用 accent，但**仅此一枚**实心；次级仍文字链。

**禁止：** 外阴影、hover scale 抬起、双实心、主钮旁再贴 outline「次主」。

## 4. 放置（owned 工具栏）

| 断点 | 布局 |
|---|---|
| ≤640 | **第一行：** 屑 + 主 CTA（主 CTA 右或 sticky 尾）；**第二行：** 故事/翻页；样张链跟在返回旁或第二行末，仍 muted |
| ≥768 | 单行：左屑 · 中/右主 CTA · 右端故事/翻页；「返回这本」紧邻主 CTA 左侧为文字链；样张最弱 |

Intro 区若重复主 CTA：与 sticky **文案与样式同一份**；滚动后 sticky 保留主 CTA，intro 可只留标题——**禁止**上下两个不同文案的主钮。
